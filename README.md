# MonthSalaryCat

STM32CubeIDE project for playing a monochrome Yuexinmiao animation on a 128x64 I2C OLED display.

## Hardware

- MCU project generated by STM32CubeMX / STM32CubeIDE
- OLED: GME12864-49 or similar 128x64 SSD1306/SSD1315 I2C module
- Wiring:
  - GND -> GND
  - VCC -> 3.3V
  - SCL -> I2C1_SCL
  - SDA -> I2C1_SDA
- OLED I2C address in STM32 HAL format: `0x3C << 1`

## Project Layout

- `Core/Inc/oled_i2c.h`, `Core/Src/oled_i2c.c`: minimal HAL I2C OLED driver
- `Core/Inc/yuexinmiao_oled_frames.h`: generated 128x64 OLED animation frames
- `tools/make_yuexinmiao_oled_frames.py`: reproducible frame generation script
- `assets/yuexinmiao_original.gif`: imported source preview used by the generator
- `build/oled_preview/`: desktop preview GIF, contact sheet, and per-frame PNGs
- `STM32CubeIDE/`: STM32CubeIDE project metadata and linker script

## Build

Open the `STM32CubeIDE` folder as the project in STM32CubeIDE, then refresh, clean, build, and download.

The generated frame header uses SSD1306/SSD1315 page order:

- 128x64 pixels
- 8 pages
- 128 bytes per page
- 1024 bytes per frame

## Regenerating Frames

```sh
python3 tools/make_yuexinmiao_oled_frames.py
```

The current source asset is a preprocessed 128x64 preview GIF, not the highest quality original animation source.
